# Educational review and objective-to-evidence blueprint — v0.9 draft

Content edition: `ptd-learning-draft-2026-10-03`. Existing v1/v2 bundles are unchanged. This is an authored formative activity for supervised clinical-year students, not a clinical competence certification. Clinical wording, Thai editorial accuracy and image permissions await educator approval.

## Design review

The case sequence remains 6/5/4. Assessment and treatment run in parallel; the transient response precedes remote-CT planning; the arrival binder context precedes imaging interpretation. No dose, additional radiographic finding, definitive operative pathway or extra pre-class question was added. The fictional report remains authoritative, not the supplied illustrative AP image.

The [NBME item-writing guide](https://www.nbme.org/sites/default/files/2021-02/NBME_Item%20Writing%20Guide_R_6.pdf) informs focused lead-ins, clinically plausible alternatives and comparable language. The 15 decisions retain five A, five B and five C keys. Review was qualitative, not a psychometric validation. In the new edition, repeated blind catheter attempts, complete-transection claims and a mechanism-only operation are replaced by realistic errors of timing, scope or coordination. Binder alternatives now use anatomical landmarks. Other retained alternatives represent identifiable novice misconceptions rather than unrelated jokes.

Learners explain the three handovers before options appear. The chart and references stay accessible: this is supported retrieval and reasoning, not a closed-book recall examination. First reasons are stored as immutable preparation events and used in the core handover response. Confidence is optional and never changes reward. Corrective feedback now requires explicit acknowledgment after a correct retry. This acknowledges review, not proof that a learner understood the text.

Feedback uses supplied evidence → significance → supervised action. A completion summary distinguishes initial responses, corrected responses and discussion topics. Later authored retrieval/comparison in class is informed by [Larsen et al., 2009](https://pubmed.ncbi.nlm.nih.gov/19930508/); the research does not validate this particular game or establish clinical mastery.

## Faculty interpretation and advice

Reward is an engagement measure. First-response and corrected evidence are different signals. A correct option can be guessed; a correction can reflect recognition after explanation. Discuss the actual rationale using the manual rubric; no automatic free-text grading is provided. Teacher observations remain a separate staff-only record and never resolve learner badges or change game reward.

Class priorities show aggregate misconceptions with observed denominators. Individual review displays the exact version's stem/options, selected answers, corrections, confidence and three handovers. Do not diagnose inability from nonparticipation or missing uploads. Check access and submission first.

## Clinical discrepancy and boundaries

H18 describes immediate binder release after a negative AP image. The seed's supervised reassessment remains the game rule: binder context can mask injury, and removal requires an agreed senior/team pathway. Educators must reconcile this handout wording with [BOAST pelvic-fracture guidance](https://www.boa.ac.uk/resource/boast-3-pdf.html) and institutional practice before approving the activity.

Meatal bleeding raises suspicion, not a confirmed extent. Avoid independent student or repeated blind attempts. [BOAST urological-trauma guidance](https://www.boa.ac.uk/resource/boast-14-pdf.html) allows an experienced clinician's appropriate pathway, including a single gentle attempt in relevant circumstances; the game does not teach a universal ban on every clinician catheter attempt.

Educational review is draft. A clinical educator must sign off all EN/TH text, corrective explanations, image interpretation and the institution's trauma/binder/urological pathways.
